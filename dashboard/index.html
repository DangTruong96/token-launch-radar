How the value model works

What might today’s locked capital imply at a comparable token valuation?

TVL × category multiple × growth × age × breadth

The category multiple starts with the median market-cap/TVL of already-tokenised peers in the same category, derived from this snapshot. It is blended with the global median according to peer count; categories without peers use the global median. The model then adjusts for 7-day TVL change, years running with no token (using tracked age), and number of chains.

These are this entry’s own estimates, not predictions that a token will launch or guarantees of rewards.
